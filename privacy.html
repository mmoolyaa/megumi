Privacy Policy

Last updated: 18 October 2026

This policy describes how Hermes ("the app") handles Google user data. Hermes is a personal, self-hosted AI assistant used by a single individual — its owner. It is not a commercial product and is not offered to the public.

What data the app accesses

  • Gmail (read-only) — message metadata and content, used to search and summarise the owner's own mail at the owner's request. The app requests the gmail.readonly scope and therefore cannot send, draft, modify, label, or delete email.
  • Google Calendar — calendar events, used to display schedules, detect conflicts, and create or remove events at the owner's explicit request.

How data is used

Data is used solely to answer the owner's requests and to carry out actions the owner asks for. It is processed on the owner's own hardware.

How data is stored

Mail and calendar content is not stored on any server operated by the app. OAuth credentials are stored locally on the owner's machine, in a file readable only by the owner's user account. Any notes the owner chooses to keep are stored in the owner's own local files.

Data sharing

No Google user data is sold, rented, transferred, or disclosed to any third party. No advertising, profiling, or analytics services are used. No Google user data is used to train or improve machine learning models.

Limited Use compliance

Hermes' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention and deletion

Data is retained only for as long as it is needed to serve the owner's requests. The owner can delete all stored credentials at any time, which removes the app's access entirely.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revocation immediately ends the app's ability to read Gmail or Calendar data.
